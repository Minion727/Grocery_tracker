# Grocery Manager
# About the Project

Grocery Manager is a simple Python command-line project for managing a grocery shopping list.

It helps the user add grocery items, view and update items, mark items as purchased, calculate expenses, and manage a shopping budget.

# Features
* Add grocery items
* View shopping list
* Update item details
* Remove items
* Mark items as purchased
* View purchased items
* View items by category
* Calculate total expense
* Set shopping budget
* Check remaining budget

# Technologies Used

* Python
* Python lists
* Python dictionaries
* Functions
* Loops
* Conditional statements
* User input and output

# Requirements

* Python 3 installed on the computer
* Command Prompt, Terminal, or VS Code

No external Python libraries are required.

# Project Files

The project contains Python files/modules for the different parts of the Grocery Manager.

The main program provides the menu through which the user can access the different features.

# How to Run

# Step 1: Install Python

Install Python 3 on your computer if it is not already installed.

# Step 2: Download or Clone the Project

Download the project from GitHub or clone the repository.

# Step 3: Open the Project Folder

Open the project folder in VS Code or a terminal.

# Step 4: Run the Program

Run the main Python file using:

```bash
python main.py
```

If your main file has a different name, run that Python file instead.

# How to Use

After starting the program, a menu will be displayed.

Choose a number from the menu to perform an operation.

For example:
1. Add Item
2. View Shopping List
3. Update Item
4. Remove Item
5. Mark Item as Purchased
6. View Purchased Items
7. View Items by Category
8. View Total Expense
9. Set Budget
10. Exit

Enter the required information when the program asks for it.

# Testing

The following basic operations can be tested:

* Add an item and check whether it appears in the list.
* Update an item's information.
* Remove an item.
* Mark an item as purchased.
* Check items using a category.
* Check the total shopping expense.
* Set a budget and check the remaining amount.
* Enter an invalid menu option and check the program response.

# Notes

This is a basic command-line Python project. The shopping list and budget are stored while the program is running.
No external database or library is required.
